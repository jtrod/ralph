# Ralph

Drive iterative development loops with Claude using a live TUI dashboard. Ralph spawns `claude -p` processes against a PROJECT file, displaying real-time progress in tasks, output, and cost.

See [ralph-prd.md](ralph-prd.md) for detailed documentation.

## Quick Start

1. **Install:**
   ```bash
   npm install github:jtrod/ralph
   ```

2. **Generate your PRD file** in Claude Code (this is the file ralph reads):
   ```
   /prd "describe your project here"
   ```

3. **Start the loop** against the file `/prd` produced:
   ```bash
   npx ralph example_prd.md
   ```

## Usage

```bash
npx ralph <prd-file> [iterations=10] [--budget <usd>] [--parallel]
```

**Arguments:**
- `<prd-file>` — Path to the PRD file generated by `/prd`
- `[iterations=10]` — Max iterations (default: 10, sequential mode)
- `[--budget <usd>]` — Max USD to spend
- `[--parallel]` — Run each `### Wn` work group as a concurrent wave (see below)
- `[--max-parallel <n>]` — Cap concurrent agents per wave (default: 6, implies `--parallel`)

### Parallel mode

By default Ralph runs one task per iteration, sequentially. With `--parallel`, every task in a
work group (`### W1`, `### W2`, …) runs **at the same time**, each in its own isolated git worktree;
groups still run in order. After a group's agents finish, Ralph merges each task's branch back to
your base branch **one at a time**, runs your test suite (`npm test` if present) after each merge,
and on a conflict or test failure rolls that task back and retries it on its own. Ralph — not the
agents — records task check-offs and `PROGRESS.md` entries after a successful merge.

Requirements and contract:
- Must be run inside a **git repository with a clean working tree**.
- Tasks in the **same group must touch disjoint files** (two tasks editing the same file will
  conflict and fall back to a slow sequential retry). Put dependent or file-sharing tasks in
  **different** groups — `/prd` documents this rule.

## Requirements

- **Node.js** >= 18
- **Claude CLI** on your PATH ([install](https://docs.claude.com/claude-code))
- **Terminal:** Real TTY for dashboard; use `ralph.sh` for CI
